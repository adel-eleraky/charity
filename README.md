# Subul - Charity Platform

Subul is a MERN Stack Charity Platform, where users can donate to different Charities. This repository contains the frontend for the website.

## Features
- **User Authentication:** Secure login and registration system.
- **Donation Management:** Users can donate to various causes easily.
- **Cause Listing:** Browse and explore different charity initiatives.
- **Responsive Design:** Fully responsive and mobile-friendly UI.
- **Redux State Management:** Efficient state handling with Redux.

## 🛠️ Technologies Used
- **React.js** (Frontend framework)
- **Redux Toolkit** (State management)
- **React Router** (Client-side routing)
- **Axios** (API requests handling)
- **Bootstrap** (Styling)
- **formik** (form handling)
- **yup** (form validation)
- **aos** (animation)

## 🏗️ Installation & Setup

1. **Clone the repository**
```sh
$ git clone https://github.com/adel-eleraky/charity.git
$ cd charity
```

2. **Install dependencies**
```sh
$ npm install
```

3. **Start the development server**
```sh
$ npm run dev
```

The app should now be running at `http://localhost:5173/`.
